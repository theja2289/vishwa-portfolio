# Vishwa Theja Pokala — portfolio

Static portfolio site. No build step: `index.html` plus the clips in `assets/`.

Publish on GitHub Pages: Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`.

Product video: copy the two renders from the work PC into `assets/` as
`gelly-engine.mp4` (full, 1:41) and `gelly-engine-30s.mp4` (30 s cut).
The page shows the poster frame until those files exist, then turns on the player.

# Vishwa Theja Pokala, portfolio

Live at https://theja2289.github.io/vishwa-portfolio/

A static site. No build step: `index.html` plus the media in `assets/`.

- The opener is a 3D lab (three.js) with a gantry you drive to six benches; a 2D floor plan takes over where WebGL is unavailable.
- Simple view (`#simple`) is a plain one-column version; the resume lives at `#resume` with a PDF in `assets/`.
- Games in the Fun corner are embedded from their own GitHub Pages sites.
- The Technology Summit 2025 poster is `assets/traceability-poster.jpg`, a render of the Claude Design canvas it links to.
- Product film: copy `gelly-engine.mp4` (full, 1:41) and `gelly-engine-30s.mp4` into `assets/`; the player appears by itself.

Deploy: commit and push to `main`. GitHub Pages serves the root of the branch.

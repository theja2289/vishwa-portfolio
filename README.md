# Vishwa Theja Pokala, portfolio

A static site. No build step: `index.html` plus the media in `assets/`.

- The opening stage is the real Gelly Engine start-up screen (`assets/gelly-scene.js`, inlined into the page).
- Games in the Play section are embedded from their own GitHub Pages sites.
- Product film: copy `gelly-engine.mp4` (full, 1:41) and `gelly-engine-30s.mp4` into `assets/`; the player appears by itself.

Publish on GitHub Pages: Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`.
